Reference clusters from the knowledge vault, one per standard, regulation or framework. Each cluster page is the map of its notes: provenance, structure, controls or articles, comparisons and controversies, plus a dated position and a list of anchors to primary sources. The notes were written from public sources and model knowledge; no standards text was machine-processed for them.

> [!warning] Every page in this space is a vault note that has not been reviewed against the standard or regulation it describes. Use it as a map, and read the primary text before relying on a clause.
