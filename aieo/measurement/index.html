    AIEO Measurement

    Three instruments can show whether AI answers cite this site. What each one counts, what it leaves out, and where each one stands.

    The answer, in one paragraph. Three instruments can show whether AI answers cite machinebehavior.io: the Generative AI performance report in Google Search Console, the AI Performance report in Bing Webmaster Tools, and a probe that sends a fixed list of questions to Perplexity's API and logs the sources in each answer. On 2026-10-09 none of the three feeds a number to this site. Setting them up is an open decision for the site owner. This page records what each instrument counts and leaves out. It carries no baseline, because no run exists.

    Search Console, in more detail

    • Google launched the report on 2026-06-03 for a subset of sites. A note on the announcement reads: As of August 31, 2026, we've rolled out these insights to all websites worldwide.
    • The same account holds the Search generative AI control, which sets whether a site's links and content can appear in AI Overviews, AI Mode and generative AI features in Discover. Include is the default for every property. Whether this property's setting differs from the default is visible only inside Search Console and is not checked here.
    • Google on outside tools: No third-party tool has access to our internal ranking or AI systems.

    Bing, in more detail

    • Microsoft launched AI Performance as a public preview on 2026-02-10.
    • Microsoft states that the report counts citations only: AI Performance does not measure rankings, authority, performance, or importance. It simply shows which content was cited.
    • Microsoft adds a warning about the trend view: Changes in citation trends are observational and do not indicate the impact of any single update, model change, or content modification.

    The probe, if it is built

    The design below is a plan. Nothing in it has run.

    1. A fixed question set. Ten to twenty questions in three groups: definitions of terms this site defines, questions about the site and its author, and problems the site's pages answer. The list is dated and hashed before the first run, the same way the experiments hash their predictions, so the questions stay fixed while the answers change.
    2. A fixed schedule. The same questions once a week, three samples per question, because one answer is one sample.
    3. One row per answer. Date, model identifier, question id, the cited URLs in order, whether a machinebehavior.io page is cited and which one, whether the page's own definition appears verbatim, paraphrased or not at all, and the other domains cited.
    4. A public record. The log as a CSV in the repository, next to the site's other run records.

    Stefan Coetzee runs one public test against these instruments: a term experiment with a prediction hashed on 2026-10-09, read by hand until the probe is built.

    What this page will not publish

    • A baseline before a run exists.
    • Numbers from third-party tracking tools.
    • A claim that a lever on this site caused a citation. The two first-party reports count citations and do not attribute them to a cause.
