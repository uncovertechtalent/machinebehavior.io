    decisions

    Where the company stands, and the big technical decisions.

    RFCs, architecture decision records, and a review of the decision log, with a gate check that every record has a status, an owner, and a date.

    • Version 0.1.0
    • 3 skills
    • 1 gate check
    • Running on this site: Decision log

    What it does

    A decision log for a repository. Larger changes start as a request for comments (RFC) with a fixed comment window. Each decision ends up as a numbered architecture decision record (ADR) with its context, the decision and its consequences. Records are never deleted: a replaced record gets the status superseded and names its successor, and the successor names it back. A gate check reports ADRs whose front matter breaks this format.

    Install

    Add the marketplace at release v0.4.0 once, then install the plugin and restart Claude Code.

    claude plugin marketplace add uncovertechtalent/cto-powersuit#v0.4.0
claude plugin install decisions@cto-powersuit

    Skills

    • /decisions:adr

      Record one decision as a numbered architecture decision record (ADR) with context, decision and consequences, from an accepted or rejected RFC or directly for a small decision.

    • /decisions:decision-log-review

      Sweep the decision log in docs/decisions/ and report what needs attention: records missing status, owner or date, proposed ADRs older than 30 days, RFCs past comments_close still in draft or review, broken supersede links, duplicate numbers, decisions past their review_by date, and a spot check of a few accepted decisions against the code.

    • /decisions:rfc

      Write a request for comments (RFC) from a problem statement and run it to a decision: draft, open for comments until comments_close, decide, then hand the outcome to the adr skill, which writes the decision record and links back.

    Source

    The CTO powersuit is a set of agent skills, one module per CTO function from the deploy gate to the hand-over, that one person uses to run a company's whole engineering platform. decisions is one of its 19 plugins, published by Stefan Coetzee.
