    Runbooks

    owner Stefan Coetzeecreated 2026-10-09updated 2026-10-09reviewed 2026-10-09review by 2027-01-071 min readreference

    Each runbook covers one failure that has happened, with how to see it, the cause and the fix. Observability runbooks (Loki, Grafana) are in the Observability space.

    SymptomRunbook
    The deploy job did not run; the conformity job is redGate blocked a deploy
    git push is rejected after a successful runPush rejected after a deploy
    site.consistency fails with a relative link that is not in the page textLink check flags a template string

    Child pages

    • Gate blocked a deployThe conformity job failed, so the deploy did not run and the previous build is still live; find the failing check, fix the page, push again.
    • Push rejected after a deployThe conformity bot commits after every run, so main moves without you; rebase on it and push again.
    • Link check flags a template stringThe gate reads every href in the page source, including ones inside JavaScript template strings; build such links with a.href in code.
