    The fields

    In the front matter of each source file: owner (who keeps the page true), reviewed (the date the page was last checked against the system or source it describes, or no), review_by (the date of the next check; 90 days after the review by default) and type. For a hand-written page, the date it was written from the source counts as its first review. How to set them: Docs tree.
