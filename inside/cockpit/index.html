    The eight areas

    The areas of the CTO job, as on the CTO powersuit pages, each with the plugins that do its work and its open items. An item's area and kind are labels on the issue: area:delivery, kind:finding. A finding is a gap that an audit or a review found, a decision is a choice still to make, and an action is work to do. Leads are counted only. Blocked and in progress come from the labels status: blocked and status: in progress; an open pull request counts as in progress. Closed in 7 days counts issues closed as done and pull requests merged.

    What the cockpit is

    The cockpit is the view in which Stefan Coetzee runs his work: every task, finding, and decision is an issue with one label for its area of the CTO job and one for its kind, and the cockpit shows the issues by area, with a scorecard for each area and the trend. His own install runs on beads, a local issue tracker, and its data stays on his machine. This page runs the same view on his public work, so everything on it is public already.

    The CTO powersuit is a set of agent skills, one module per CTO function from the deploy gate to the hand-over, that one person uses to run a company's whole engineering platform. The cockpit is that person's view of the work. For a company, the plan is that the plugins' read-only audits write their findings into the areas, so the scorecard shows what is open in each part of the CTO job.

    Read from the public repositories of uncovertechtalent on GitHub: agent-observability, cto-powersuit, machinebehavior.io, tychat.io, vault-kit, vestige-kit.

    • Board: the issues of this site by status, with filters.
    • Mission Control: the live operations view, with the gate and deploy state of the three sites.
    • CTO powersuit: the plugins by area, with install commands for the latest release.

    Cockpit · data: cockpit.json, read from the GitHub API at each deploy of this site and checked against a contract before the page is written; the deploy gate runs the same check on the committed copy. How it works: Cockpit page. Decision record: ADR-0031.
