    How the board works

    The column comes from the status label on each issue: status: ready, status: in progress or status: blocked. An open issue without one sits in Backlog; a closed issue is Done for 30 days. Labels also set the type, the area and the priority, P0 first.

    The deploy job reads the issues from the GitHub API and writes issues.json next to this page, so opening the board sends no request to GitHub. New reports appear here once a maintainer gives them a type label. Details, labels and the workflow: Ticket board in the Engineering docs.
