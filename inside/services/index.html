    Services

    12 services run the platform: the three sites, the gate and the deploy job, the build tools, the observability stack, the research tools and the agent sessions. Each one has an owner, a tier, a lifecycle and the links an on-call responder needs. The catalog is built from one YAML file per service, validated at build; updated 2026-10-09.

    • Tier 1 Readers meet it directly, or it decides whether a deploy goes out. First in line when something breaks.
    • Tier 2 Keeps the platform observable and the research running: data, dashboards, search, the agents. Fixed the same day.
    • Tier 3 Tooling a reader does not meet directly. Waits for the next working session.
